# GPU training
# ------------
# The pin above installs the CPU build, which trains far too slowly to be
# practical. For an NVIDIA GPU, replace it after installing the rest:
#
#   pip install torch==1.12.1+cu113 --extra-index-url https://download.pytorch.org/whl/cu113
#
# That wheel bundles its own CUDA runtime, so no separate CUDA/cuDNN install is
# needed. Verify with:
#
#   python -c "import torch; print(torch.cuda.is_available())"
#
# Notes
# -----
# - The dataset is not in this repository. It is pulled from
#   https://huggingface.co/datasets/NightRaven/bangla-emergency-posts
#   and cached under ~/.cache/huggingface, so the first run needs network
#   access. Override the source with the DATASET_REPO environment variable.
# - pandas is imported by train.py but not actually used; it can be dropped
#   from both the import and this file.
